# 5. Technical Findings

---

## 5.1 SMBv1 Enabled on Router

### Summary

The router supports SMBv1 (NT LM 0.12), which is deprecated and insecure.

### Evidence

```bash
nmap -p445 --script smb-protocols 192.168.1.254
```

Result:

```
NT LM 0.12 (SMBv1) [dangerous, but default]
```

---

### Additional Enumeration

```bash
smbclient -L //192.168.1.254 -N --option='client min protocol=NT1'
```

Shares discovered:

```
storage
IPC$
```

---

### RPC Enumeration

```bash
rpcclient -U "" -N 192.168.1.254 --option='client min protocol=NT1'
```

```bash
netshareenum
```

Result:

```
netname: storage
path: C:\tmp\media
```

---

### Impact

* Potential unauthorized file access
* Legacy exploit compatibility
* Weak authentication model

---

## 5.2 Telnet Service Exposure

### Summary

Telnet service is exposed with login prompt:

```
GEN8 login:
```

---

### Risk

* Plaintext credentials
* Possible default credentials
* Full system compromise if accessed

---

## 5.3 IoT Device Information Disclosure (Google Nest)

### Summary

Unauthenticated API exposed via port 8008.

---

### Evidence

```bash
curl http://192.168.1.146:8008/setup/eureka_info
```

Revealed:

* Device name
* Wi-Fi SSID
* MAC address
* Firmware version
* Timezone
* Public key

---

### Impact

* Reconnaissance
* Device fingerprinting
* Privacy leakage

---

## 5.4 IoT Control Without Authentication

### Summary

Google Nest allows control endpoints without authentication.

---

### Tested Endpoints

```bash
curl -X POST http://192.168.1.146:8008/setup/reboot
```

```bash
curl http://192.168.1.146:8008/apps/YouTube
```

---

### Impact

* Remote control of device
* Potential abuse (DoS, annoyance)

---

## 5.6 SNMP Exposure (No Response)

### Summary

SNMP port is open but does not respond.

---

### Evidence

```bash
sudo nmap -sU -p161 192.168.1.254
```

```bash
snmpwalk -v2c -c public 192.168.1.254
```

Result:

```
Timeout: No Response
```

---

### Interpretation

* SNMP likely restricted or filtered
* Still increases attack surface

---

Commands worked:
